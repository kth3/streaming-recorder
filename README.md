# Streaming Recorder

브라우저가 받은 스트리밍 영상·음성 데이터를 원본 압축 상태로 저장하는 Chrome 확장입니다. 라이브와 일반 영상에 사용할 수 있으며, 영상 주소로 추가 다운로드 요청을 보내거나 화면을 다시 인코딩하지 않습니다.

## 설치와 사용

1. Chrome 119 이상에서 확장 관리 페이지를 열고 개발자 모드를 켭니다.
2. **압축해제된 확장 프로그램을 로드합니다**를 눌러 이 폴더를 선택합니다.
3. 녹화할 영상 탭을 새로고침하고 재생합니다. 확장 변경 후에는 확장과 영상 탭을 모두 새로고침합니다.
4. 해당 탭에서 확장 아이콘을 누르고 **녹화 시작**을 선택합니다.
5. **녹화 중지**를 누르면 영상과 음성을 병합해 저장합니다. 같은 탭에서 다시 녹화를 시작할 수 있습니다.

팝업을 닫거나 다른 탭을 선택해도 녹화는 유지됩니다. 현재는 한 번에 한 탭을 녹화합니다. 여러 영상이 있는 탭에서는 최근 수신 영상이 선택됩니다. 재생 문서가 교체되거나 연결이 종료되면 녹화를 마무리합니다. 단순한 탭 로딩 알림은 녹화를 종료하지 않습니다.

## 저장

기본 위치는 Chrome 다운로드 폴더입니다. **폴더 지정**으로 다른 폴더를 선택할 수 있습니다. 지정 폴더 권한이 해제되면 현재 파일을 보관하고 **저장** 버튼에서 다시 허용받습니다. 기본 폴더로 자동 전환하지 않습니다.

수신 조각은 확장 전용 디스크 공간에 순차 기록합니다. 녹화 전체를 RAM에 쌓지 않습니다. 녹화 시작 전에 수신한 오디오는 트랙당 최근 16MiB까지 메모리에 보관하며, 녹화 시작 시 함께 기록합니다. 시작 전에 수신한 영상 전체를 보관하는 기능은 없습니다.

중지 후 재인코딩 없이 병합합니다. 기본 출력은 MP4이며 코덱에 따라 MKV를 사용합니다. 호환되는 구간은 한 파일로 묶고 코덱·해상도 변경으로 호환되지 않는 구간은 분할 저장합니다. 첫 키프레임 이전 구간은 제외됩니다. 오디오 트랙 선택이 모호하거나 초기화 정보가 없으면 오류를 표시합니다.

지정 폴더에 직접 저장한 파일은 Chrome 다운로드 목록에 나타나지 않습니다. 중간 데이터와 병합본은 자동 삭제하지 않으므로 최종 파일보다 많은 디스크 공간이 필요합니다. 확장 제거 또는 브라우저의 확장 저장 공간 삭제는 내부 데이터를 지울 수 있습니다. 비정상 종료된 녹화의 복구·저장 기록 기능은 없습니다.

## 개인정보와 지원 범위

- 쿠키·로그인 토큰을 읽지 않으며, 원격 미디어 요청·사용 통계·원격 로그 전송을 하지 않습니다. 라이브러리는 확장에 포함됩니다.
- 페이지 제목은 팝업 표시에만 사용합니다. 페이지 주소와 제목을 녹화 파일명이나 진단 로그에 저장하지 않습니다.
- 사이트가 원래 보내는 재생·인증 요청은 그대로 발생합니다. 확장은 해당 요청을 대신하거나 차단하지 않습니다.
- 로컬 진단 로그에는 최근 100개 상태·오류·종료 원인이 남습니다. 팝업에서 확인하거나 비울 수 있습니다. 오류의 주소·로컬 경로·대표적인 인증값은 가림 처리합니다.
- MP4·WebM 기반 MediaSource와 실제 미디어 Blob을 지원합니다. DRM, WebRTC, Worker 내부 전용 MediaSource, 직접 URL 재생은 지원하지 않습니다.
- 수집을 위해 페이지의 미디어 함수를 감쌉니다. 페이지가 이를 검사할 가능성이 있으므로 감지 불가능을 보장하지 않습니다.

## 권한

`tabs`는 현재 탭 식별과 제목 표시에, `storage`는 로컬 상태·로그 보관에, `downloads`는 완성된 로컬 파일 저장에 사용합니다. `offscreen`은 디스크 기록과 병합을 담당하며 영상 재생을 수행하지 않습니다. `unlimitedStorage`는 장시간 녹화를 위한 확장 저장 공간에 사용됩니다. 페이지 수집 스크립트는 HTTP·HTTPS 페이지의 프레임에서 실행됩니다.
